Create Quiz from JSON

Import questions from a JSON file to create a named, categorized quiz that can be assigned to students.

JSON Format: 
{
  "topic": "Optional Topic Name",
  "questions": [
    {
      "text": "Question text?",
      "difficulty": 3,
      "tags": ["tag1"],
      "answers": [
        {"text": "Correct answer", "is_correct": true},
        {"text": "Wrong answer", "is_correct": false}
      ]
    }
  ]
}
