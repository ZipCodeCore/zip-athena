Question Management

Import Questions from JSON
JSON Format: Upload a JSON file with the following structure: 
{
  "topic": "Topic Name",
  "questions": [
    {
      "text": "Question text?",
      "difficulty": 3,
      "tags": ["tag1", "tag2"],
      "answers": [
        {"text": "Correct answer", "is_correct": true},
        {"text": "Wrong answer 1", "is_correct": false},
        {"text": "Wrong answer 2", "is_correct": false},
        {"text": "Wrong answer 3", "is_correct": false}
      ]
    }
  ]
}
Notes:
  • Difficulty must be between 1 (easiest) and 7 (hardest)
  • Each question must have 2-6 answers with exactly one marked as correct
  • Duplicate questions (by text) will be skipped
Questions from the JSON file will be assigned to this topic
