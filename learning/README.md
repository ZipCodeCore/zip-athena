# Athena Learning Resources

Welcome to the Athena Learning Module! This is your friendly guide to mastering programming concepts in Java and Python. Each topic is designed to help you understand language features, see them in action, and build confidence through clear examples.

## About This Module

The learning resources here are designed with you in mind. They're written in a conversational, approachable style—think of it as having a knowledgeable friend walk you through each concept. No stuffy textbook language here!

These resources are directly linked to the quiz questions you'll encounter in Athena, so everything you study has a purpose. As you move through the material, you'll build a solid foundation that prepares you for real-world coding.

## Structure

The learning resources are organized by programming language, with each major topic getting its own file:

### Java
- **control-structures.md** - Making decisions and repeating actions in Java
- **variables-and-data-types.md** - Understanding how Java stores and works with data

### Python
- **control-structures.md** - Making decisions and repeating actions in Python  
- **data-structures.md** - Working with lists, dictionaries, sets, and tuples (covers curriculum sections 6-9)

## How to Use These Resources

1. **Read through each section** - Don't rush. Take your time to understand the concepts.
2. **Try the examples** - Type them out yourself. It really helps!
3. **Experiment** - Modify the examples and see what happens.
4. **Link to quizzes** - After studying a topic, take related quizzes to reinforce your learning.

## Style Guide

All learning materials follow these principles:
- **Familiar and friendly** - We talk to you like a person, not a textbook
- **Practical examples** - Every concept includes working code you can try
- **Clear explanations** - We break down complex ideas into digestible pieces
- **Encouraging tone** - Learning to code is challenging, and we're here to support you

Happy learning! 🚀
